# Sport Shoes

فروشگاه نمونهٔ فارسی کفش ورزشی به‌همراه پنل مدیریت نمایشی. برای اجرا به وب‌سرور دارای PHP نیاز دارد؛ فایل‌های PHP را با بازکردن مستقیم از فایل‌سیستم اجرا نکنید.

## استقرار روی هاست اشتراکی یا زیرمسیر

1. محتوای پروژه را در `public_html` یا پوشه‌ای مانند `public_html/x/` بارگذاری کنید و ساختار پوشه‌ها (`admin/`، `admin/vendor/`، `includes/` و `store-assets/`) را حفظ کنید.
2. صفحهٔ شروع فروشگاه `index.php` است؛ پنل نمایشی در `admin/index.html` قرار دارد.
3. برای استقرار در زیرمسیرهایی مانند `/x/`، نشانی منابع را نسبی (`./assets/...` یا `assets/...`) نگه دارید یا در `<head>` از `<base href="/x/">` استفاده کنید. از مسیر مطلق ریشه مانند `/assets/...` پرهیز کنید؛ این مسیر به ریشهٔ هاست اشاره می‌کند، نه پوشهٔ نصب.
4. فایل `Sport-Shoes-shared-hosting.zip` نسخهٔ قابل بارگذاری بدون فایل‌های تصویری محلی پروژه است. تصاویر خارجی که در داده‌های نمونه به نشانی اینترنتی ارجاع داده شده‌اند، همچنان به اتصال اینترنت نیاز دارند.

## نکتهٔ امنیتی PHP در هاست اشتراکی

اسکریپت‌های PHP بارگذاری‌شده با سطح دسترسی حساب cPanel اجرا می‌شوند. در هاست اشتراکی، ایزولاسیون کرنل/داکر برای جداکردن این اسکریپت‌ها وجود ندارد؛ بنابراین فقط کدهای مطمئن و بازبینی‌شده را بارگذاری و اجرا کنید. این هشدار در پایین صفحهٔ فروشگاه هم نمایش داده می‌شود. این پروژه نمایشی است و پنل، سبد خرید و فرم تماس آن به بک‌اند متصل نیستند.

قالب مدیریتی حجیم از شاخهٔ اصلی GitHub حذف شده است؛ منابع ضروری رابط مدیریت در `admin/vendor/` نگهداری می‌شوند و ZIP بدون تصاویر محلی ساخته می‌شود.
