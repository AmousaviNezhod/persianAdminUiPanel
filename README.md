# Sport Shoes

فروشگاه نمونهٔ فارسی کفش ورزشی به‌همراه پنل مدیریت نمایشی. برای اجرا به وب‌سرور دارای PHP نیاز دارد؛ فایل‌های PHP را با بازکردن مستقیم از فایل‌سیستم اجرا نکنید.

## استقرار روی هاست اشتراکی یا زیرمسیر

1. محتوای پروژه را در `public_html` یا پوشه‌ای مانند `public_html/x/` بارگذاری کنید و ساختار پوشه‌ها (`admin/`، `includes/`، `larken/` و `store-assets/`) را حفظ کنید.
2. صفحهٔ شروع فروشگاه `index.php` است؛ پنل نمایشی در `admin/index.html` قرار دارد.
3. ارجاع‌های داخلی به صفحات، استایل‌ها، اسکریپت‌ها، فونت‌ها و فایل‌های نمونه نسبی‌اند تا در زیرمسیر نیز به همان پوشهٔ نصب اشاره کنند. آن‌ها را به مسیرهای ریشه‌ای مانند `/assets/...` تبدیل نکنید.
4. فایل `Sport-Shoes-shared-hosting.zip` نسخهٔ قابل بارگذاری بدون فایل‌های تصویری محلی پروژه است. تصاویر خارجی که در داده‌های نمونه به نشانی اینترنتی ارجاع داده شده‌اند، همچنان به اتصال اینترنت نیاز دارند.

## نکتهٔ امنیتی PHP در هاست اشتراکی

اسکریپت‌های PHP بارگذاری‌شده با سطح دسترسی حساب cPanel اجرا می‌شوند. در هاست اشتراکی، ایزولاسیون کرنل/داکر برای جداکردن این اسکریپت‌ها وجود ندارد؛ بنابراین فقط کدهای مطمئن و بازبینی‌شده را بارگذاری و اجرا کنید. این پروژه نمایشی است و پنل، سبد خرید و فرم تماس آن به بک‌اند متصل نیستند.
